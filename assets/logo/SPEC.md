# OmniNotation Logo 矢量重建规范 v1

> 用途：在 Figma / Illustrator / 代码中按本规范重建标志，产出 SVG 与多尺寸 PNG。
> 数据来源：对 `assets/logo/omninotation-logo-v1.png`（1024×1024）逐像素量取，非目测估算。

## 一、色彩（⚠️ 实测值，非 KnoWeave 色板）

**重要**：定稿位图的实际颜色与 KnoWeave 品牌色板**不一致**。生成环节产生了系统性色偏。重建时**按本表取值**，不要用 KnoWeave 色板，否则与已有素材对不上。

| 部位 | 实测色值 | 说明 |
|---|---|---|
| 椭圆环 | `#009775` | 偏暖的祖母绿，非 KnoWeave 青绿 `#14B8A6` |
| 内横条 ×2 | `#009775` | 同环 |
| 收笔圆点 | `#009775` | **同环色**（见下方「已知偏差」） |
| 标准字 | `#009775` | 同环色 |

### 已知偏差（重建时需人工校正）

1. **两色调已塌缩**：设计意图是「青绿环 + 深松绿圆点/字」双色调，定稿实际全部是同一个 `#009775`。重建时若要恢复双色调，参考「二、色彩方案」。
2. 深色模式对比度：松绿 `#064E3B` 在近黑底上几乎不可见，深色版必须换字色。

### 色彩方案（二选一）

**方案 A — 忠于定稿**（与现有全部素材一致）
```
主色  #009775
```
单色调标志。最省事，所有已产出素材一致。

**方案 B — 恢复双色调**（更贴合设计意图，且与 KnoWeave 家族一致）
```
环 / 内条   #14B8A6  KnoWeave 青绿
圆点 / 字   #064E3B  KnoWeave 深松绿
深色模式字色 #E8F5F1  浅薄荷白（仅深色底使用）
```

## 三、画法步骤（Illustrator / Figma）

```
1. 画椭圆（不用椭圆工具直接调，用矩形转椭圆更可控）
   宽 504、高 397，圆心对齐画布 (511.5, 443)
   描边 50，描边居中，端点平头

2. 切出断口
   在 30°–60° 区间（右上偏上）用形状生成器/布尔运算切掉一小段
   断口宽度 ≈ 60–80（略大于线宽，两端留出平头）

3. 放收笔圆点
   圆心 (678, 306)，直径 77，置于断口外侧

4. 加内横条
   两条 400×53 矩形，圆角 0
   第一条 y=375，第二条 y=465（间距 38）
   水平居中于 511.5

5. 加标准字
   OmniNotation，中等字重，紧排，字色同方案
   基线置于 y≈765，字标与图标间距 25
```

## 五、最小尺寸可读性检查

定稿已验证：环 + 双条 + 圆点在 **16px** 下仍能读出「圈住两行文字」。缩小时：

- 圆点直径降到 1.2px 会糊 → 16px 版本建议省略圆点，只保留环 + 双条
- 双条间距（38 / 53 ≈ 0.72）足够在小尺寸下保持两条可辨
- **不要**为省事在 16px 下换成单一实心色块，会丢掉全部识别特征

## 六、遗留问题

1. **色偏未修正**：定稿是 `#009775`，与设计的 `#14B8A6` / `#064E3B` 双色调不一致。重建时先定方案 A 或 B。
2. **位图不可用于品牌延伸**：色偏 + 位图精度 = 任何正式物料都必须从矢量重建，不要从 PNG 放大或抠图。
3. 圆点精确尺寸存在测量不确定（水平 110 vs 垂直 77），重建时取 77–90 区间实测调整。

# OmniNotation Logo 矢量重建规范 v1

> 用途：在 Figma / Illustrator / 代码中按本规范重建标志，产出 SVG 与多尺寸 PNG。
> 数据来源：对1024×1024 基准画布逐像素量取 + 矢量解算，非目测估算。
>
> **当前状态**：矢量定稿已完成，`omninotation-logo-v1.svg` 为唯一权威源文件。
> 下方「实测色偏」一节保留为历史记录 —— 那是位图初版的问题，已在矢量重建中修正。

## 一、色彩（KnoWeave 双色调，已定稿）

定稿矢量与 KnoWeave 品牌色板**精确一致**，逐像素校验零偏差。

| 部位 | 色值 | 来源 |
|---|---|---|
| 椭圆环 | `#14B8A6` | KnoWeave 青绿 |
| 内横条 ×2 | `#14B8A6` | 同环 |
| 收笔圆点 | `#064E3B` | KnoWeave 深松绿 |
| 标准字 | `#064E3B` | 同圆点 |

像素验证（1024×1024 主版）：青绿约 88,737 px，深松绿约 29,774 px。

### 深色模式

松绿 `#064E3B` 在近黑底上几乎不可见，深色版必须换字色：

| 部位 | 深色模式色值 |

| 环 / 内条 | `#14B8A6` 保持不变 |

## 二、几何参数（以 1024×1024 画布为基准）

### 图标区（环 + 内条 + 圆点）

| 项 | 定稿值 | 说明 |
|---|---|---|
| 椭圆中心 | (511.5, 443) | 画布水平居中 |
| 椭圆中线半轴 |227 × 173 | 椭圆率 0.763 |
| 环线宽 | **50** | 描边居中 |
| 视觉包围盒 | x 259.5–763.5，y 245–641 | 宽 504 × 高 396 |
| 断口 | 右上45° 楔形（中心 (511.5,443) → (820,443) → (820,190)） | 遮罩实现，不影响内条 |

**环的画法**：椭圆率仅 0.763（偏扁），这是标志的关键识别特征 —— **不要画成正圆**。

> ⚠️ 早期规格里的「椭圆半宽 252 / 半高 198」是**外缘**尺寸，已改为中线半轴 227 / 173，两者相差半个线宽（25）。

### 内部横条（⚠️ 已修正）

原始规格写「条宽 400」是**错的** —— 400 超过椭圆内腔可用宽度，会与环相接并贯穿边框。已按内腔重新解算。

| 项 | 定稿值 |
|---|---|
| 内腔半轴 | 202 × 148（中线半轴减去半个线宽） |
| 条带可用全宽 | 358.8（条1）/ 348.3（条2），越靠外越窄 |
| **条 1** | x 340, y 375, **宽 343**, 高 53 |
| **条 2** | x 346, y 465, **宽 332**, 高 53 |
| 条间距 | **38**（约为条高的 0.72 倍） |
| 端点 | 平头（方端，无圆角） |

条 2 比条 1 短且略右移，是对椭圆内腔的**光学补偿** —— 数学等宽的两条在偏心圆里看起来会左重右轻。**不要**把它们改成等宽。

### 为什么要小尺寸补偿版

主版几何在 32px 下环线仅约 2.1px、双条约 2.4px、条间仅约 1.0px，抗锯齿后**两条糊成一条灰带**，「圈注文字」语义消失，只剩一个 "C"。

1024 基准 → 32px 换算：1 基准px ≈ 0.040 输出px。要让特征在 32px 下可分辨，基准尺寸下限为：

| 特征 | 需要的输出尺寸 | 基准下限 | 补偿版取值 |
|---|---|---|---|
| 环线 | ≥ 2.8px | ≥ 70 | **72** |
| 条高 | ≥ 3.0px | ≥ 75 | **78** |
| 条间距 | ≥ 1.6px | ≥ 40 | **40** |

补偿版同时把圆点放大到 ⌀92 并收窄条宽以适配加粗后的内腔。断口与收笔圆点保留，维持识别点。

实测 32px 逐行不透明度剖面（中心列）：上壁 3px / 条1 4px / 缝 2px / 条2 4px / 下壁 4px —— 两条清晰可分辨。

**48px 及以上必须回到主版**，补偿版的加粗会让大尺寸下显得笨重。

## 五、最小尺寸可读性

**已实测验证**：主版几何在 32px 下两条糊成灰带，**不可用**。因此提供独立的小尺寸补偿版（见「三、为什么要小尺寸补偿版」）。

| 尺寸 | 应使用 | 验证结果 |
|---|---|---|
| 48px 及以上 | 主版 |✅ 环 / 双条 / 圆点全部清晰 |
| 32px | 补偿版 | ✅ 剖面 3/4/2/4/4px，两条可分辨 |
| 16px | 补偿版 | ⚠️ 语义仍可读，但细节已损失；favicon 场景可接受 |

**不要**为省事在 16px 下换成单一实心色块，会丢掉全部识别特征。

## 六、遗留问题

1. **标准字未转曲**：SVG 里是 `<text>`，依赖系统字体。正式发布物料前需在 Figma/Illustrator 中转曲。
2. **深色模式资产未产出**：规范已给色值，但深色版 PNG/SVG 尚未导出。
3. **商店主图未排版**：440×280 需要专门的横向版式（图标 + 字 + 副标），不是现有 1:1 资产的缩放。
4. **位图不可用于品牌延伸**：任何正式物料都必须从 `omninotation-logo-v1.svg` 重建，不要从 PNG 放大或抠图。
